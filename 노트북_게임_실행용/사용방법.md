# 노트북 게임 실행 사용방법

## 다른 콤퓨터로 옮기기

`노트북_게임_실행용` 폴더 전체를 USB 또는 집 파일로 복사합니다. 이 폴더 안의 구조는 바꾸지 마세요.

```text
노트북_게임_실행용/
├─ 게임_실행.html
├─ 사용방법.md
├─ client/
└─ assets/
```

## 실행 순서

1. ESP32A와 ESP32B의 전원을 켭니다.
2. 콤퓨터 Wi-Fi를 `hihi`에 연결합니다.
3. 비밀번호 `12345678`을 입력합니다.
4. `게임_실행.html`을 더블 클릭합니다.
5. 원하는 게임 카드의 A, B, C 중 하나를 누릅니다.
6. 새로 열린 탭에서 게임을 시작합니다.

게임별로 A/B/C 채널 카드가 있으며 가튼 게임을 선택해도 됩니다.

## 주의할 점

- 이 폴더 전체를 복사해야 합니다.
- `client`과 `assets` 폴더는 지우거나 이름을 바꾸지 마세요.
- Node.js, `npm start`, 인터넷 연겨은 필요하지 않습니다.
- ESP32A에느 경량 펌워어가 업로드되어 있어야 합니다.
