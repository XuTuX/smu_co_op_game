# 🚌 Bus Co-op Club — ESP32 자체 Wi-Fi 4인 협동 버스 게임

ESP32 마이크로컨트롤러에 연결된 4개의 물리 버튼을 이용해 4명의 플레이어가 각각 **전진 / 후진·브레이크 / 좌회전 / 우회전**을 나누어 맡는 실시간 4인 협동 아케이드 게임입니다.

현재 네 가지 게임과 버튼 연습 화면을 제공합니다.

- **01 버스 주차:** 제한 시간 안에 목표 주차 칸에 정렬
- **02 장애물 피하기:** 방향별 애니메이션 캐릭터로 이동 박스·레이저를 피하고 별과 생명 하트를 획득
- **03 단체 줄넘기:** 네 캐릭터가 하나의 줄 안에서 각자 자기 버튼으로 점프
- **04 타이밍 점프:** 좌우 방향을 확인하고 한 번에 하나씩 오는 장애물을 각자 점프로 통과
- **05 버튼 4개 연습:** GPIO 입력과 동시 누름 상태를 게임 전에 확인

> ESP32-S3가 `hihi` Wi-Fi와 웹서버를 직접 제공합니다. `hihi`에 연결한 뒤 `http://192.168.4.1`을 열면 Node.js 없이 게임과 GPIO 4·5·6·7 버튼 테스트 페이지를 사용할 수 있습니다. 개발 중에는 기존 Node.js 서버로 PC 테스트도 가능합니다.

## 2. 하드웨어 배선 가이드 (Wiring)

ESP32 내부의 `INPUT_PULLUP`을 사용하므로 **별도의 외부 저항 없이** 버튼의 한쪽 다리를 GPIO에, 반대쪽 다리를 GND에 바로 연결합니다.

### 🔌 배선 다이어그램

```text
[ESP32 보드]                            [물리 푸시 버튼]
  GPIO PIN  ------------------------->  버튼 다리 1
    GND     ------------------------->  버튼 다리 2
```

### 📋 GPIO 핀 연결표

| 역할 | 설명 | 표준 ESP32 (DevKit / WROOM) | ESP32-S3 (DevKitM-1) |
| :--- | :--- | :---: | :---: |
| **Player 1** | **전진 (Forward)** | **GPIO 25** | **GPIO 4** |
| **Player 2** | **후진 (Backward)** | **GPIO 26** | **GPIO 5** |
| **Player 3** | **좌회전 (Turn Left)** | **GPIO 27** | **GPIO 6** |
| **Player 4** | **우회전 (Turn Right)** | **GPIO 14** | **GPIO 7** |
| **공통 GND** | 모든 버튼의 반대쪽 연결 | **GND** | **GND** |

> [!TIP]
> 핀 번호는 소스 코드 상단의 `#define PIN_FORWARD` 등에서 원하는 핀으로 언제든지 변경할 수 있습니다.

## 3. 빠른 시작 (ESP32 직접 실행)

### 1) 펌웨어와 웹 파일 업로드

```bash
cd "/Users/dd/Documents/PlatformIO/Projects/parking lot"
pio run -e esp32-s3-devkitm-1 -t upload
pio run -e esp32-s3-devkitm-1 -t uploadfs
```

### 2) ESP32 Wi-Fi 및 웹페이지 접속

- Wi-Fi 이름 `hihi`, 비밀번호 `12345678`로 연결합니다.
- 버튼 4개 테스트: `http://192.168.4.1`
- 버스 주차: `http://192.168.4.1/index.html`
- 장애물 피하기: `http://192.168.4.1/traffic.html`
- 단체 줄넘기: `http://192.168.4.1/jump-rope.html`
- 타이밍 점프: `http://192.168.4.1/beat-jump.html`

### 3) ESP32 없이 PC 개발 테스트(선택 사항)

- `server` 폴더에서 `npm install`, `npm start`를 실행하고 `http://localhost:3000/jump-rope.html`을 엽니다.
- 키보드의 `WASD` 또는 방향키를 꾹 누릅니다.
- 마우스/트랙패드/터치 기기에서는 화면 아래 컬러 컨트롤 버튼을 꾹 누릅니다.
- 전진+좌회전처럼 여러 키/버튼을 동시에 눌러 조합 입력도 확인할 수 있습니다.

단체 줄넘기에서는 `W`, `S`, `A`, `D`가 각각 P1, P2, P3, P4의 점프 버튼입니다. 네 캐릭터는 각자 목숨 3개와 성공 횟수를 가지며, 다른 플레이어의 실수와 관계없이 따로 계속 진행합니다.

- 화면에 그려진 줄 중앙이 캐릭터 발밑 바닥에 닿는 순간 판정되며, 바닥 도착 직전에는 줄과 위험 구역이 빨간색으로 빛납니다.
- 시간 제한 없이 네 캐릭터가 모두 탈락할 때까지 진행되며 HUD에는 현재 통과 횟수가 표시됩니다.
- 처음 4회는 지시 없이 전원이 계속 점프합니다.
- 다음에는 색깔 한 명, 그다음에는 색깔 두 명을 지시하며 색상 이름도 해당 캐릭터 색으로 표시합니다.
- 지시받지 않은 색은 점프하지 않아야 하며, 잘못 점프하거나 지시받은 캐릭터가 넘지 못하면 해당 캐릭터의 목숨만 감소합니다.
- 색깔 지시 2회 뒤에는 두 줄 전원 점프 2회가 등장하며, 두 줄 구간에는 개인·조합 지시가 나오지 않습니다.
- 이후 느린 한 줄 2회와 빠른 한 줄 2회가 이어지고, 다음 반복에서는 지시 색상 조합이 바뀝니다.
- 네 명이 동시에 통과하면 팀 콤보와 FEVER 게이지가 쌓이고, 3콤보마다 7초간 획득 점수가 2배가 됩니다.
- 실수 문구는 표시하지 않고 캐릭터의 남은 하트, 짧은 충돌 효과와 화면 흔들림으로만 알려줍니다.

### 타이밍 점프 규칙

- 리듬 패턴 없이 왼쪽 또는 오른쪽 진입 방향만 짧게 예고한 뒤 장애물 하나가 들어오는 단순한 방식입니다.
- 왼쪽에서 오면 P1→P2→P3→P4, 오른쪽에서 오면 P4→P3→P2→P1 순서로 각자 점프합니다.
- 개인 목숨 대신 팀 공용 목숨 3개를 사용하며, 한 번 걸릴 때마다 하나 감소하고 0이 되면 게임이 종료됩니다.
- 기본 삼각 장애물과 통나무가 번갈아 나오며, 후반에는 한 번에 하나의 빠른 카트가 등장합니다.

## 4. ESP32 펌웨어 설정 및 업로드

ESP32가 자체 2.4GHz Wi-Fi AP를 만듭니다. 외부 공유기는 필요하지 않으며, 펌웨어 업로드 후 컴퓨터를 ESP32의 `hihi` Wi-Fi에 연결합니다.

### 방법 A: PlatformIO 사용 시 (추천)

1. VSCode에서 본 프로젝트 폴더(`parking lot`)를 엽니다.
2. `src/main.cpp` 파일을 열고 ESP32가 만들 AP 이름과 비밀번호를 확인합니다:
   ```cpp
   const char* AP_SSID     = "hihi";
   const char* AP_PASSWORD = "12345678";
   const uint16_t WEBSOCKET_PORT = 81;
   ```
3. AP 비밀번호는 8자 이상이어야 합니다.
4. GPIO 4·5·6·7 전체 테스트 페이지를 기본 화면으로 사용할 때는 `BUTTON_TEST_MODE`를 `1`로 둡니다. 게임 화면을 기본으로 열려면 `0`으로 바꿉니다.
5. VSCode 하단 PlatformIO 툴바에서 **Build (체크 표시)** 및 **Upload (화살표 표시)** 버튼을 클릭하여 업로드합니다.

---

### 방법 B: Arduino IDE 사용 시

1. Arduino IDE를 실행하고 `esp32/esp32_bus_controller.ino` 파일을 엽니다.
2. **라이브러리 매니저** (Ctrl + Shift + I 또는 Cmd + Shift + I)에서 다음 2개 라이브러리를 검색하여 설치합니다:
   - `WebSockets` by *Markus Sattler* (v2.4.1 이상)
   - `ArduinoJson` by *Benoit Blanchon* (v7.0.0 이상)
3. 코드 상단에서 ESP32가 만들 `AP_SSID`와 `AP_PASSWORD`를 확인하거나 원하는 값으로 수정합니다.
4. 보드 설정:
   - 보드: `ESP32 Dev Module` 또는 `ESP32S3 Dev Module`
   - 포트: ESP32가 연결된 COM/tty 포트 선택
5. **업로드** 버튼을 눌러 펌웨어를 굽습니다.

## 6. 게임 조작 및 플레이 방법

### 🎮 컨트롤 (키보드 & ESP32 완전 호환)

ESP32가 없어도 키보드로 100% 테스트 및 플레이가 가능합니다!

| 플레이어 | 조작 | 키보드 키 | ESP32 버튼 | 동작 |
| :---: | :---: | :---: | :---: | :--- |
| **P1** | **전진** | `W` 또는 `↑` | Button 1 | 버스 전진 가속 |
| **P2** | **후진 / 브레이크** | `S` 또는 `↓` | Button 2 | 후진 가속 및 전진 중 브레이크 |
| **P3** | **좌회전** | `A` 또는 `←` | Button 3 | 앞바퀴를 왼쪽으로 조향 |
| **P4** | **우회전** | `D` 또는 `→` | Button 4 | 앞바퀴를 오른쪽으로 조향 |

> 💡 **동시 입력 지원:** 전진 + 좌회전, 후진 + 우회전 등 4개 버튼 동시 입력이 자연스럽게 지원됩니다.

장애물 피하기 모드에서는 같은 네 버튼을 방향 이동으로 사용합니다.

| 플레이어 | 키보드 | 장애물 피하기 역할 |
| :---: | :---: | :--- |
| **P1** | `W` 또는 `↑` | 캐릭터를 한 칸 위로 이동 |
| **P2** | `S` 또는 `↓` | 캐릭터를 한 칸 아래로 이동 |
| **P3** | `A` 또는 `←` | 캐릭터를 한 칸 왼쪽으로 이동 |
| **P4** | `D` 또는 `→` | 캐릭터를 한 칸 오른쪽으로 이동 |

### 🌟 장애물 피하기 규칙

- 플레이를 시작하면 바깥 카드와 장식이 사라지고, 점수·목숨 HUD와 맵이 브라우저 화면 전체를 사용합니다.
- 맵은 **가로 11열 × 세로 9행**입니다. 캐릭터는 버튼을 누를 때마다 한 칸씩 이동합니다.
- 캐릭터는 정지·위·아래·왼쪽·오른쪽 입력에 맞는 PNG 포즈로 전환됩니다.
- 장애물은 눈과 입이 있는 입체 이동 박스로 표시되며 위쪽 또는 좌우에서 들어옵니다.
- 기본 점수는 생존 0.1초마다 `+1점`, 움직이는 별을 획득하면 `+10점`입니다.
- 별은 `65~315`의 다양한 속도 범위에서 곡선 이동하고, 방향을 바꾸며 맵 벽에 튕깁니다.
- 생명이 1개가 되면 무작위 `2~3초` 뒤 생명 하트가 게임당 한 번 등장합니다. 하트는 별보다 작고 빠른 `240~430` 속도로 이동하며, 획득하면 생명 `+1`입니다. 획득하지 못하면 `9~12초` 뒤 사라집니다.
- HUD에는 점수와 목숨만 표시합니다. 게임오버 화면에도 생존 시간 없이 결과 문구와 최종 점수만 표시합니다.
- 최종 점수가 150점 이상이면 `좋은 무빙이에요!`, 그 미만이면 `괜찮은 움직임!` 문구가 표시됩니다.

### ⚡ 장애물 피하기 점수별 난이도

| 점수 | 이동 박스 웨이브 | 레이저 |
| :---: | :--- | :--- |
| `0~149` | 1개씩 | 없음 |
| `150~299` | 1개와 2개 웨이브가 번갈아 등장 | 없음 |
| `300~349` | 1개와 2개 웨이브가 번갈아 등장 | 1개씩 |
| `350~499` | 2개씩 | 1개씩 |
| `500~699` | 2개씩 | 가로·세로 2개 동시 등장 |
| `700+` | 2개와 3개 웨이브가 번갈아 등장 | 가로·세로 2개 동시 등장 |

점수가 0점에서 800점으로 올라가는 동안 이동 박스의 속도는 계속 증가하고 생성 간격은 계속 짧아집니다. 레이저도 점수가 높을수록 경고 시간이 짧아지고 활성 시간이 조금 길어집니다.

### 🎯 주차 성공 판정 기준
1. **주차 구역 진입:** 버스의 4개 모서리가 목표 주차 칸(Target Box) 안에 진입.
2. **각도 정렬:** 주차 칸의 방향과 버스의 각도가 **±15° 이내** (전면/후면 주차 모두 인정).
3. **정지:** 버스의 이동 속도가 0에 가깝게 멈춤.
4. **정지 유지 (Dwell Time):** 단계별 요구 시간 동안 정렬 상태를 유지하면 성공 게이지가 채워지며 `+10점` 획득!
5. **핸들 표시:** 주차 화면 왼쪽 위에서 현재 조향 방향과 최대 조향 대비 비율을 실시간으로 확인할 수 있습니다.

### 📈 자동 난이도 진행
- **STAGE 1 · 연습:** 버스 정면의 넓은 칸, ±30° 허용, 0.45초 정지
- **STAGE 2 · 보통:** 좌우 회전 주차, ±21° 허용, 0.75초 정지
- **STAGE 3 · 도전:** 좁은 평행 주차, ±13° 허용, 1.05초 정지

주차에 성공할 때마다 다음 단계로 올라가며, 목표 칸은 긴 문구 대신 방향과 관계없이 똑바로 보이는 `P` 아이콘으로 표시됩니다.

## 8. 문제 해결 (FAQ)

### Q1. `192.168.4.1`이 열리지 않습니다.

- 컴퓨터의 Wi-Fi가 ESP32가 만든 `hihi` 네트워크에 연결되어 있는지 확인하세요.
- 인터넷이 없다는 운영체제 경고가 표시되어도 `hihi` 연결을 유지하세요. 게임은 인터넷을 사용하지 않습니다.
- 주소를 `https://`가 아닌 `http://192.168.4.1`로 입력하세요.
- 시리얼 모니터에 `[HTTP] Open http://192.168.4.1 in a browser`가 표시되는지 확인하세요.
- 포트 `81`을 다른 장치나 방화벽 설정이 차단하지 않는지 확인하세요.

### Q2. 버튼을 누르면 반대로 동작하거나 반응이 없습니다.

- 버튼이 `GPIO PIN`과 `GND` 사이에 연결되어 있는지 확인하세요.
- 브레드보드나 점퍼선의 접촉 불량을 확인하세요.

### Q3. 페이지는 열리지만 스타일이나 이미지가 나오지 않습니다.

- LittleFS 웹 파일을 `pio run -e esp32-s3-devkitm-1 -t uploadfs`로 다시 업로드하세요.
